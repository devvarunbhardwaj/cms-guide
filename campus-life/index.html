Where to edit Campus Life

The Campus Life menu has one hub page (/campus-life), ten facility pages (Banking, Classrooms, Food Courts, Healthcare, Hostels, Laundry, Library, Sports, Student Clubs, Transportation) and the Events page. Their content lives in six places in the CMS. This guide shows which place holds which part of the page.

Every change needs Save, Publish, then Publish to website. Until you press Publish to website, the live site doesn't change.

/campus-life

Hub page

Top

Hero

Site · Route › path /campus-life › title, lede.

01

Photo gallery

Home · Campus Life › galleries. One entry per tab (max 5). Pick the tab in group and add photos to images. Portrait versions go in images_mobile, in the same order.

02

Panorama

Page · Campus Life › panorama, at most 3 frames. Each frame has an image, an eyebrow, a title and a body.

03

Facility cards

Page · Campus Life › facilities. Each card has a name, a body, an image and an href (the page it opens).

04

Hostel table

Page · Campus Life › hostel_heading + hostel_facts (label / value).

05

Video reel

Home · See Us In Action. Changing it also changes the home page.

/campus-life/<facility>

Facility pages

Banking, Classrooms, Food Courts, Healthcare, Hostels, Laundry, Library & e-Resources, Sports & Fitness, Student Clubs and Transportation all use Page · Leaf. Open Content Manager › Page · Leaf and pick the entry whose site_route matches the page.

Page · Leaf fields

same on every facility page
FieldWhat it is
introThe line under the page title. If empty, the lede from Site · Route is used.
blocksThe page sections, in order. Each one is listed in the side menu.
blocks › anchor_idInternal ID used by the side menu. Lowercase letters and dashes. Don't change it on existing blocks.
blocks › labelName shown in the side menu.
blocks › titleThe big heading of the section.
blocks › indexSmall number above the heading: 01, 02…
blocks › paragraphsOne entry per paragraph (field text).
blocks › image / image_wideOptional photo for the section. Tick image_wide for a full-width photo.
galleryPhoto groups. group_id is the internal ID, label is the tab name and images holds the photos. anchor_id places the gallery under that block; leave it empty to put it under the last block.

Alt text for every photo is set once in the Media Library (click the photo › Alternative text), not on the page.

/campus-life/hostels

Hostels

Sections and photos are in Page · Leaf › /campus-life/hostels, like any facility page. The fact picker beside the photo (Rooms, Mess, Wi-Fi…) reads Page · Campus Life › hostel_facts, the same list as the hub table, so one edit updates both pages.

hostel_facts fieldWhat it is
labelThe fact name, e.g. Rooms.
valueThe fact itself, as printed on the page.
imagePhoto the picker shows for this fact. The hub table ignores it.
/campus-life/student-clubs

Student Clubs

Page · Leaf › /campus-life/student-clubs has three extra lists.

FieldWhat it is
chipsThe row of category buttons. label = text; anchor_id = the section it jumps to.
club_groupsOne entry per category. key = internal ID (lowercase-with-dashes), label = category name, clubs = the clubs (name + body).
event_calendarOne row per event: event, club, department (optional), month and week.
event_calendar_periodThe period the calendar covers, e.g. 2025–26.

/campus-life/events

Events

Add a new event

  1. Content Manager › Data · Campus Event › Create new entry.
  2. Fill title, date (free text, e.g. 12–14 Feb 2026), body and category.
  3. slug: lowercase-with-dashes. Don't change it once published.
  4. order: position in the list (1 = first).
  5. photos: add the event pictures.
  6. Optional fields:
    • organiser.
    • school / programs: shows the event on those pages too.
    • news_slug: links to a news article.
  7. Save › Publish › Publish to website.
