How it fits

Four places make one About page

Site · NavMenu → ABOUT US column: label and link of each item, in order.
↓
Site · RouteOne per address (filter path). Hero eyebrow, title, lede, hero image, SEO, bottom band, menu label.
↓
Page entryThe page's own content: text, cards, photos. Listed per page below.
↓
Data listsData · Leader, Data · Governing Body, Data · Placed Student. One entry per person or body.

Most About pages share one entry: Page · About. Its fields are prefixed with the page they fill, e.g. Core Values · Values. Section headings for all of them sit in All pages · Band headings.

Rules

Five things that break pages

Never change a key

Band heading keys, label keys, anchor ids, slugs, approval keys. The site finds content by them. Edit the text, not the key.

Empty hides

An empty field or list removes that part of the page. Nothing is filled in for you.

Keep the tokens

{year}, {n}, {label} and *red words* are filled or styled by the site. Type around them.

New page = developer

Adding a Site · Route or a menu item does not create a page. Never edit a route's path.

Images

Upload in the Media Library and fill the alt text. The original file is served as-is, so keep photos under ~500 KB.

Publish

From edit to live

  1. Save the entry.
  2. Publish the entry (top right). A draft never reaches the site.
  3. Open Website in the left menu → Publish to website.
  4. The site is rebuilt and uploaded. Changes appear after that.

Publishing an entry also publishes any draft changes another editor saved in it. Check the entry before you publish.
