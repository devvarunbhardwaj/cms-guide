Programme code (program_code)

This is the ID. These all use it:

  • curriculum
  • landing page courses (programme_code)
  • related programmes, lateral entry (parent programme)
  • menu programme cards
  • school programme variants

Never change a code. If you do, all of the above lose the link.

Slug, discipline, show on website

  • slug = the last part of the URL. Changing it changes the link, and old links stop working.
  • discipline = which school page it is listed on.
  • show on website = off hides it everywhere: school page, menu, landing pages, related programmes.
  • The school page lists every programme with the same discipline.

SEO & sharing

1. Google search result

culucknow.com › programs › business › mba
① MBA at Chandigarh University UP
② Two-year MBA with industry projects, placements and…

① seo_title: max 70 letters

② seo_description: max 160 letters

Landing pages: meta_title and meta_description.

2. When someone shares the link (OG)

OG = "Open Graph". It is the preview card on WhatsApp, Facebook, LinkedIn and X. Edit it in the page's seo block.

③ og_image · 1200 × 630 px
④ og_title
⑤ og_description
culucknow.com

③ og_image: JPG or PNG, 1200 × 630 px.

④ og_title: short, like the seo title.

⑤ og_description: one line.

Left empty? The page uses its seo title, seo description and hero image.

WhatsApp keeps the old preview for a while. To check now:

Facebook debugger ↗   LinkedIn inspector ↗   opengraph.xyz ↗

3. Keywords (meta_keywords)

5 to 10 search words, separated by commas. Example: MBA Lucknow, MBA Uttar Pradesh, Chandigarh University MBA, MBA admission 2027

Google mostly ignores keywords. Fill them in, but don't spend long on them.

4. Schema (schema_json): optional

Extra facts for Google, written in a fixed format. Google can use them to show a richer result (course details, FAQ, article date).

  1. Copy the template that matches the page.
  2. Change only the text inside the quotes "…".
  3. Paste it into seo → schema_json.
  4. Test it: Google Rich Results Test ↗ or Schema validator ↗. Choose "Code" and paste.

Keep every { }, [ ], " and ,. If the JSON is broken, the site ignores it, and the publish still goes through.

Programme page · Course
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "Master of Business Administration",
  "description": "Two-year MBA with industry projects.",
  "provider": {
    "@type": "CollegeOrUniversity",
    "name": "Chandigarh University, Uttar Pradesh",
    "sameAs": "https://culucknow.com"
  }
}
Blog / News · Article
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Article title here",
  "datePublished": "2026-10-17",
  "image": "https://culucknow.com/uploads/photo.jpg",
  "author": {
    "@type": "Organization",
    "name": "Chandigarh University, Uttar Pradesh"
  }
}
Page with questions · FAQ
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is the fee for MBA?",
      "acceptedAnswer": { "@type": "Answer", "text": "Answer here." }
    }
  ]
}
Home / About · University
{
  "@context": "https://schema.org",
  "@type": "CollegeOrUniversity",
  "name": "Chandigarh University, Uttar Pradesh",
  "url": "https://culucknow.com",
  "logo": "https://culucknow.com/uploads/logo.png"
}

More types: schema.org ↗

5. Canonical

The page's one official address, as a full link: https://culucknow.com/programs/business/mba. Leave it empty unless you are told to fill it.

Make a new landing page

  1. Content Manager → Page · Landing Page → Create new entry.
  2. path: small letters, numbers and - only, e.g. mba-up. Page = /lp/mba-up.
  3. Fill position, meta_title, meta_description.
  4. hero: title + image (required).
  5. sections → Add a component → pick the type → fill it.
  6. Save → Publish → Publish to website.

Fastest: open an existing page, then use Duplicate and change the path.

Section order and banner

  • section_order empty = standard order. listed = exactly the order in the list.
  • Each section needs an anchor (e.g. courses). It must be different for each section on a page.
  • The banner shows only when all 3 are set: bannerDesktop, bannerTablet, bannerMobile.
  • Landing pages are hidden from Google (noindex).

How to…

Publishing
Put your change on the live site
  1. In the entry: Save, then Publish.
  2. Left menu → Website → Publish to website. Press it once.
  3. Wait about 7 minutes, then refresh the page (Ctrl + Shift + R).
  4. Still old? Check you pressed Publish on the entry, and that you edited the right one (use Find a page).
Fix a failed publish
  • "… is empty": a required (*) field is blank. Fill it.
  • "not published": open that entry and press Publish.
  • "dropped row": one item in a list has a blank required field. Fill it or delete the item.
  • "is not a date": use the date picker, do not type the date.
  • Nothing on the live site changes until a publish succeeds.
Make words red in a heading
  1. Put * on both sides of the words: Why Choose *Engineering* at CU-UP?
  2. The words between the stars show in red italic. It works in most headings (landing pages, home, popup).
  3. Always use a pair of stars. One star alone shows as a star.
Upload images the right way
  • Fill both image and image_mobile when there are two. Mobile = tall crop.
  • In the Media Library, open the image → fill Alternative text (what the picture shows).
  • Share images (og_image): 1200 × 630 px.
  • Use JPG for photos, PNG for logos. Keep files under 500 KB.
Programmes
Change a programme's fee, duration or eligibility
  1. Data · Program → search the programme name or code.
  2. Fee: fee_per_semester (Indian), fee_saarc, fee_international, fee_duration.
  3. Other facts: duration, eligibility, eligibility_criteria.
Add a new programme
  1. Data · Program → Duplicate a similar programme (faster than empty).
  2. Change program_code (must be new), program_name, title, slug (the URL part).
  3. discipline = the school it is listed under. show_on_website = on.
  4. Add its curriculum (next item). Without it, the default curriculum shows.
Hide a programme
  1. Data · Program → open it → show_on_website = off.
  2. It disappears from the school page, menu, landing pages and related lists. Do not delete it.
Add or change a curriculum
  1. Data · Curriculum → Create new entry (or open the programme's one).
  2. program → pick the programme.
  3. semesters → Add an entry → number (1, 2, 3…) → courses → name, lecture, tutorial, practical, credits.
  4. objectives → code (e.g. PEO1), body, kind = peo or pso.
Change the CUCET scholarship table on a programme
  1. Data · Program → cucet_phases.
  2. Each phase: title, display_title (short, e.g. "CUCET Phase I"), slabs.
  3. Each slab: parameters (the score band), scholarship_amount, amount_to_pay (numbers only).
Add placed students to a programme
  1. Data · Placed Student → Create: name, company, photo, company_logo.
  2. Data · Program → placed_students → pick them. placed_students_cohort = the batch, e.g. "2025".
  3. quote only if the student really said it.
Add top recruiters to a programme
  1. Data · Program → recruiters → Add: name, logo.
  2. whiten = on when the logo is dark (the band is black).
  3. Empty list = the campus-wide recruiters show instead.
Add career pathways (jobs after the programme)
  1. The job must exist in Data · Career role (title, description, image, key e.g. data-scientist). Create it if missing.
  2. Data · Program → roles → Add: label (job name) + role_key = that key.
  3. Never change a key once it is used.
Set related programmes or lateral entry
  • related_programs: pick programmes. Empty = programmes from the same school.
  • parent_program: for lateral-entry versions, pick the main programme.
Add an HOD message
  1. Data · Program (or Data · School) → hod_message: heading, name, role, paragraphs, portrait.
  2. Empty = the Chancellor's message shows.
Show an event or news story on a programme or school
  1. Open the Data · Campus Event or Page · News Post.
  2. programs → pick the programmes. school → pick the school.
  3. Leave both empty for university-wide items.
Landing pages
Make a new landing page
  1. Page · Landing Page (ads) → open a similar page → Duplicate.
  2. Change path (small letters and -, e.g. mba-up → /lp/mba-up), sheet_name, meta_title, meta_description.
  3. Edit hero and the sections.
Add, move or remove a section
  1. sections → Add a component → pick the type (Courses, Table, Testimonials…).
  2. Drag the handle to move it. Use the bin icon to remove it.
  3. To show sections in your exact order: section_order = listed. Empty = standard order.
  4. Each section's anchor must be different on the page (e.g. courses, apply).
Link a course name to its programme
  1. In a Courses section → the course line → programme_code.
  2. Type the programme's program_code exactly (from Data · Program). The page then shows the programme card.
Set the top banner
  • hero → bannerDesktop, bannerTablet, bannerMobile.
  • The banner only shows when all three are set. Otherwise the normal hero (title + image) shows.
Pages
Change a page's top section (hero) or bottom band
  1. Site · Route → filter path = the page, e.g. /admissions.
  2. Hero: eyebrow, title, lede, hero_image, hero_image_mobile. Bottom band: cta.
  3. Programme, school, blog and landing pages keep their hero in their own entry.
Change a section heading on a page
  1. Open the page's entry (use Find a page) → sections.
  2. Find the item by its key → change eyebrow, title, lede.
  3. Never change the key. It is how the site finds the section.
Change a campus life page (Food Courts, Banking, Transport…)
  1. Page · Leaf → find the row whose site_route is the page.
  2. blocks: one per section: label (tab name), title, paragraphs, image.
  3. Also: chips, gallery, bus_routes (Transport), club_groups + event_calendar (Student Clubs).
Change a school page
  1. Data · School → filter discipline (e.g. business).
  2. Tab names and headings shared by all schools: Data · School Hub.
Change the FAQ
  1. Home · FAQ → entries → question, answer, group.
  2. scope: landing = home page, admissions = /admissions/faqs, both = both.
Add a lab, holiday, admission office or leader
  1. Create a new entry in Data · Laboratory / Holiday / Admission Office / Leader.
  2. order sets its place in the list (lowest number first).
  3. Lab: pick its school so it shows on that school and its programmes.
News, blog, events
Add a blog post or news story
  1. Page · Blog Post or Page · News Post → Create new entry.
  2. slug = the URL part, e.g. mba-admissions-2027. Never change it later.
  3. Fill title, hero image, body, seo.
  4. To show it on a programme: Data · Program → latest_articles.
Add a table to a news story
  1. tables → Add an entry.
  2. position = how many paragraphs come before it (0 = at the top).
  3. header: ["Course", "Fee"]
  4. rows: [["MBA", "₹1,00,000"], ["BBA", "₹80,000"]]
  5. Keep every [ ], " and ,. Each row has the same number of cells as the header.
Add an event
  1. Data · Campus Event → Create: slug, category, date (as it should read, e.g. "12 Oct 2026"), title, body, photos.
  2. school / programs to show it on those pages.
  3. news_slug = the slug of the news story about it (if any).
Site-wide
Change an admission deadline or countdown

The date is in four places. Change all of them together:

  • Home · Hero → countdown_deadline (the timer) and countdown_date_label (the printed date).
  • Home · Programs → cucet_deadline, cucet_deadline_label.
  • Site · Mobile Dock → register_deadline_note.
  • Site · Promo Campaign → body, body_between_phases (if they mention a date).
Turn the popup on or off
  • Site · Promo Campaign → enabled on / off (popup and deadline dock).
  • variant: image = text over a photo, text = text only.
  • programme_headline: write {programme} and it becomes the programme's name.
Change the menu or footer
  1. Top links, Apply button, dropdowns: Site · Nav.
  2. Page names in a column: Site · Route → nav_label, order. Column title: Site · Section.
  3. Footer: Site · Footer → columns, links, address, social links.
Change a button or small text
  1. Search the text's meaning in Find a field (e.g. read more, apply).
  2. Most are in Site · Labels, grouped (search, form, lp, blog…).
  3. In lists with a key, change only the text, never the key.
