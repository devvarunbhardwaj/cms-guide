Filling the live CMS from the reference site

Every single page of the site (programmes and schools excluded) was compared with the hardcoded reference, cu-lkn-hardcoded-reference.vercel.app. The CMS fields that were empty were then filled with the reference's text and photos.

All changes are saved as drafts. Only empty fields were filled, and nothing an editor had written was overwritten. Nothing reaches the website until each entry is Published and then Publish to website is pressed.
