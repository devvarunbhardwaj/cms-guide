Where the programme heading comes from

The big heading at the top of every programme page isn't one field. The site builds it from four CMS fields, three on the programme and one in Program Defaults, plus a logo. This page shows which field makes which word.

Fields

The fields, and what each one controls

In the CMS, open Content Manager → Program and the programme. The label is a single shared entry, Content Manager → Program Defaults.

FieldCMS locationAPI keyWhat it makes on screen
LogoProgram → LogologoThe partner mark above the heading. Only shown when Partner is not "Chandigarh University". If it's empty, the site falls back to the partner's favicon (Site · Nav → Partner Domains).
TitleProgram → TitletitleTwo pieces: the qualification before the ( (“M.Tech”), and the italic specialisation, which is the text inside the ( ) after the dash (“AI & ML”).
Program NameProgram → Program Nameprogram_nameThe long branch: the text inside its ( ) (“Computer Science and Engineering”). It replaces the short form (“CSE”) in the heading.
PartnerProgram → PartnerpartnerSwitches the collaboration look on (logo, “in collaboration”, the line underneath). Its name is removed from the end of Title and Program Name (“with SAS”), then printed on the line underneath.
LabelProgram Defaults → Labels → Collaboration Prefixcollaboration_prefixShared by every programme. Used whole on the line underneath (“In collaboration with SAS”), and without its last word “with” in the italic part (“in collaboration”).

How it's built

The six steps, run on LCS301

  1. Is it a collaboration? Partner = SAS, which isn't “Chandigarh University” or empty, so yes. That turns on the logo, the “in collaboration” words and the line underneath.
  2. Remove the partner from the end of Title and Program Name.
    Title M.Tech (CSE -AI & ML) with SAS Program Name Master of Technology (Computer Science and Engineering) with SAS
  3. Qualification = Title up to the first ( .
    M.Tech (CSE -AI & ML)
  4. Split the Title's brackets at the dash. Before the dash is the short branch, after it is the italic specialisation. (A bracket that only says “Hons.” is skipped.)
    ( CSE -AI & ML ) → short “CSE”, italic “AI & ML”
  5. Swap in the long branch from Program Name's brackets, if it's longer than the qualification.
    Master of Technology (Computer Science and Engineering) → “M.Tech Computer Science and Engineering”
  6. Add the label. For a collaboration, the italic part gets the Collaboration Prefix minus “with”, and the line underneath is the full prefix plus Partner.
    “AI & ML” + “in collaboration” · “In collaboration with” + “SAS”
How to change

I want to change…

“M.Tech”

Edit Title, the text before the (.

“Computer Science and Engineering”

Edit Program Name, the text inside its ( ).

The italic “AI & ML”

Edit Title, the text after the - inside its ( ). With no dash, the whole bracket becomes the italic part.

“SAS” and the logo

Edit Partner and Logo. Set Partner to “Chandigarh University” and the collaboration look disappears.

“in collaboration” / “In collaboration with”

Edit Program Defaults → Collaboration Prefix. This changes it on every collaboration programme.

Screen readers / Google

The hidden <h1> reads Title as typed, plus “In collaboration with SAS” when Title doesn't already name the partner.

Notes

Things the code does, not the editor

The italic “in collaboration” is added by code.No editor typed it, and it repeats the line underneath (“In collaboration with SAS”), so the heading reads oddly. Removing it is a one-line site change in splitProgrammeTitle (lines 202–205) — waiting for a go.
36 programmes print their specialisation twice.For example, B.Tech (Civil Engineering) shows “B.Tech Civil Engineering – Civil Engineering”. Step 5 adds the long branch to the qualification, and step 4 had already used the same bracket for the italic part. That's a site code bug, not data. A fix in programmeHeroTitle (line 227) would drop the italic part when it's already in the qualification — waiting for a go. Filter repeats below to see them.
15 programmes have no italic part, because their Title has no specialisation in brackets (e.g. “MBA”, “B.Pharm”). That's expected.
